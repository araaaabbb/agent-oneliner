A Python program that writes one fixed one-liner about AI coding agents to `/output/entry.txt`. No network and no randomness, so every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
